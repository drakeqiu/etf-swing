# ETF 波段量化

单只 ETF 日线回测工具：显式刷新并缓存行情数据，运行 SMA(20/60) 示例策略，导出可复查的回测结果。

> 本项目是研究与工程验证骨架，不是已验证有效的波段策略，也不构成投资建议。每次只回测一只 ETF；不支持组合交易、券商连接、实盘下单或信号推送。

## 能做什么

- 显式刷新日线行情、复权因子和交易日历；普通回测只读取覆盖所选区间的本地缓存。
- 运行只做多的 SMA(20/60) 长仓/空仓示例回测。
- 导出 `result.json` 汇总指标、`equity.csv` 权益曲线和 `trades.csv` 交易记录。

## 快速开始

需要 Python 3.14 和 `uv`。在仓库根目录安装项目依赖；安装需要保留 `wheels/` 中的本地 wheel：

```sh
uv sync
```

首次刷新行情还需要可用的 AmazingData 本机环境、账号和行情权限。按[快速开始指南](docs/quickstart.md)设置 `.env` 后运行：

```sh
uv run etf-swing \
  --symbol 563360 \
  --start 2024-01-01 \
  --end 2025-12-31 \
  --refresh
```

已有完整缓存时可省略 `--refresh`，无需登录行情服务。缓存范围、参数和输出说明见[完整使用指南](docs/user-guide.md)。
