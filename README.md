# ETF 波段量化

面向 ETF 策略研究的单标的日线回测工程骨架：读取行情、做前复权、运行回测，并导出可复查的结果。

> 当前策略是用于验证数据与回测流程的 SMA(20/60) 示例，不是已经验证有效的波段策略，也不构成投资建议。项目不支持多 ETF 组合、实盘下单、券商连接或信号推送。

## 完整使用指南

新手从环境准备、凭据设置、首次刷新、缓存回测到理解策略和结果的完整步骤，见[中文使用指南](docs/user-guide.md)。

## 快速开始

项目使用 Python 3.14 和 `uv`。在仓库根目录安装依赖：

```sh
uv sync
```

第一次从 AmazingData 获取行情时，先在本机 `.env` 中设置 `AMAZINGDATA_USERNAME`、`AMAZINGDATA_PASSWORD`、`AMAZINGDATA_HOST` 和 `AMAZINGDATA_PORT`，再显式刷新：

```sh
uv run --env-file .env etf-swing \
  --symbol 563360 \
  --start 2024-01-01 \
  --end 2025-12-31 \
  --refresh
```

后续在已有缓存覆盖范围内回测，不需要刷新或登录：

```sh
uv run etf-swing --symbol 563360 --start 2024-01-01 --end 2025-12-31
```

`--start` 和 `--end` 必填，日期格式为 `YYYY-MM-DD`；`--symbol` 默认是 `563360`。普通运行只读缓存，不自动下载缺失数据；缓存不完整或日期范围不匹配时会报错，需要显式使用 `--refresh` 更新。

## 当前示例策略与成本

快线（20 日收盘价简单移动平均）高于慢线（60 日简单移动平均）时持有多头，否则空仓。信号在收盘形成，下一根日线 bar 执行；仅做多、不加杠杆，初始资金为人民币 100,000 元，下单份数按 100 份取整。

单边佣金率为 `0.00005`，每笔成交最低佣金为 0.1 元；默认 `--spread 0.0005` 是回测框架的固定成本假设，不是实测点差或单边滑点。示例规则与成本假设都不代表真实策略效果。

## 数据与结果

- 行情与配套缓存默认保存在 `data/cache/`；默认结果目录为 `results/`。
- 每次运行输出 `result.json`（指标和运行参数）、`equity.csv`（权益曲线）及 `trades.csv`（交易记录）。
- 可用 `--cache-dir` 和 `--output-dir` 指定目录；可用 `--spread` 调整固定 spread 假设。
- `.env`、`data/cache/` 和 `results/` 均为本机文件，不应提交。
