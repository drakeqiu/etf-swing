# ADR-0001：单标的回测管线与数据约定

- 状态：已接受
- 决策范围：项目第一阶段的研究回测骨架
- 需求依据：[`docs/requirements.md`](../requirements.md)

## 背景

项目需要将本机 AmazingData SDK 的 ETF 日线数据转换为 `backtesting.py` 输入，并以可复现、可离线测试的方式运行单标的回测。现有目标标的是 563360；SDK 和本地 wheel 已在项目环境中配置。需求还包括复权、真实交易费用近似、结果导出和后续扩展策略的空间。

## 决策

### 1. 以单标的 CLI 回测作为第一阶段架构

每次运行只回测一个 ETF，默认 563360。采用命令行作为可重复执行入口；不以 Notebook 作为唯一业务实现。策略、数据适配、回测和导出应保持可独立测试的边界。

### 2. 隔离外部 SDK 与业务数据管线

AmazingData 登录和网络查询只存在于 CLI 运行边界。行情获取通过适配边界提供；复权、指标计算、回测和输出由项目自身逻辑处理。测试使用假提供器或合成数据，不依赖真实凭据、SDK 内部网络行为或外部服务。

### 3. 使用项目拥有的行情 CSV 缓存

AmazingData 行情查询文档未提供可依赖的行情磁盘缓存契约，因此行情缓存由项目管理为 CSV。普通调用必须读取完整覆盖请求日期区间的缓存；缓存缺失或覆盖不足时明确报错，不自动查询行情。只有显式刷新才请求新行情。因子查询可使用 SDK 已提供的本地缓存能力。缓存属于运行数据，不进入版本控制。

### 4. 明确前复权语义

根据已检查的本地 xysz 参考实现，前复权采用后复权因子比值：当日原始 OHLC 乘以“当日后复权因子 / 区间最新后复权因子”。xysz 参考实现只调整收盘价；本项目按需求将相同因子比值应用于 Open、High、Low、Close，Volume 不变。这是项目约定，而非对 SDK 默认输出的断言。因子缺失或日期无法严格对应时停止回测，不静默回退。

### 5. 固定单资产回测输入契约

向 `backtesting.py` 提供 DatetimeIndex 和 `Open`、`High`、`Low`、`Close`、`Volume` 列。第一阶段不引入多资产组合接口。标的代码从 AmazingData 的 `EXTRA_ETF` 代码表解析，避免假定本地代码后缀。

### 6. 将示例策略与最终策略区分

使用 SMA(20/60) 长仓/空仓策略验证整条流程。信号在收盘形成、下一根 bar 执行，避免收盘信号与同一收盘价成交造成前视偏差。初始资金为人民币 100,000 元；仅做多、不使用杠杆，信号开启时尽可能使用可用资金，关闭时平仓，下单数量向下取整至 100 份，未使用现金保留为现金。策略不含完整的左侧、右侧、震荡市模型，不以该示例的回测结果宣称策略有效。

### 7. 采用可审计的成本假设

佣金率为单边 0.00005，单次成交最低 0.1 元，开仓与平仓分别计费。`spread=0.0005` 是 `backtesting.py` 的固定 spread 参数值，作为框架成本假设，不代表实测点差或单边滑点。费用与关键运行参数应随回测结果一起记录，spread 应可配置。

### 8. 以三类产物支持分析与复现

每次回测输出：

- JSON：指标、标的、区间、策略参数、初始资金和成本假设。
- Profit Factor 没有亏损交易、因而无法定义时，JSON 字段输出 `null`。
- 平均持仓周期仅统计已平仓交易，按交易日 bar 数计算并注明单位。
- CSV：权益曲线。
- CSV：交易记录。

## 后果

### 正面

- 能够离线验证核心逻辑，凭据和 SDK 改动不会污染纯函数与回测测试。
- 缓存、复权参考日期和成本假设可被显式审查。
- 将来替换数据源或策略时，已有 DataFrame、回测和结果契约仍可复用。

### 代价与风险

- 单标的架构不支持组合层面的资金分配或同时持仓。
- CSV 缓存需要自行处理文件损坏、日期范围、标的区分和刷新语义；实现必须避免把旧缓存误作完整新数据。
- 固定 spread 忽略流动性、盘口深度、交易时段和成交规模影响；回测可能高估实际可成交性。
- 前复权 OHLC 扩展虽内部一致，但需以 SDK 返回字段和本地参考实现核实实际因子定义。
- Python 3.14 与 `backtesting.py` 的兼容性需以安装后的运行测试验证，包元数据声明兼容不能替代运行验证。

## 拒绝的替代方案

- **Notebook-only**：难以形成稳定 CLI、缓存与自动化端到端验收入口。
- **直接在业务逻辑中调用真实 SDK**：使测试依赖凭据/网络，并将数据供应商细节扩散到策略和回测逻辑。
- **一次实现多资产组合回测**：超出当前用户确认的初始范围；backtesting.py 的单次 `Backtest` 以单个 OHLCV 数据集为输入。
- **把 5 bp 描述为已观测滑点**：数据无此依据；只记录为经验 spread 近似。
- **复权失败时静默使用原始价格**：会造成回测输入语义不明确，故选择显式失败。

## 重新评估条件

出现以下情况时重新审视本 ADR：需要多 ETF 组合；SDK 的代码表/因子语义与本约定不一致；需要成交级滑点或盘口模拟；或确认 Python/框架组合无法在目标环境运行。
